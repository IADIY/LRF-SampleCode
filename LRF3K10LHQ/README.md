# 3km 1535nm Compact Laser Rangefinder Module - LRF3K10LHQ
## Introduction
The LRF3K10LHQ is a high-end laser rangefinder module operating at a 1535 nm wavelength, designed specifically for applications requiring compact size and lightweight form factor. Compared to traditional, bulkier 1535 nm ranging systems, the LRF3K10LHQ maintains high-performance ranging capabilities while significantly reducing its physical dimensions, offering greater integration flexibility and freedom in system design. This module can accurately measure a 2.3 × 2.3 m (NATO standard) target at a distance of 3 km, and for larger structures or natural terrain targets, the maximum measurement distance can reach ≥ 4000m.

## Communication

### UART Parameters
- Baud Rate: 115200 Default, but can be changed 
- Parity Bits: None
- Stop Bits: 1
- Byte Size: 8

### Command List
| Command | Command Code |
| --- | --- |
| Single Measurement | EE 16 02 03 02 05 |
