# 8km 1535nm High-End Laser Rangefinder Module - LRF8K10LH
## Introduction
The LRF8K10LH utilizes a 1535nm laser with excellent atmospheric penetration, and its laser divergence angle is reduced to 0.3mrad through precision optics. This allows the ranging module to measure targets of size 2.3x2.3 (NATO targets) at a distance of up to 8000m, with a maximum measurement distance of ≥10000m, compliant with laser safety class 1 standards.

## Communication

### UART Parameters
- Baud Rate: 115200 Default, but can be changed 
- Parity Bits: None
- Stop Bits: 1
- Byte Size: 8

### Command List
| Command | Command Code |
| --- | --- |
| Single Measurement | EE 16 02 03 02 05 |
