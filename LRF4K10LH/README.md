# 4km 1535nm High-End Laser Rangefinder Module - LRF4K10LH
## Introduction
The LRF4K10LH utilizes a 1535nm laser with excellent atmospheric penetration, and the laser divergence angle is reduced to less than 0.6mrad through precision optics. This allows the ranging module to measure targets of size 2.3x2.3 (NATO targets) at a distance of up to 4000m, with a maximum measurement distance of ≥5000m, compliant with laser safety class 1 standards.

## Communication

### UART Parameters
- Baud Rate: 115200 Default, but can be changed 
- Parity Bits: None
- Stop Bits: 1
- Byte Size: 8

### Command List
| Command | Command Code |
| --- | --- |
| Single Measurement | EE 16 02 03 02 05 |
